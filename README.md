# Swiggy Sales Analytics Dashboard – Excel

## Project Overview
The Swiggy Sales Analytics Dashboard is a data visualization project developed using Microsoft Excel to analyze sales performance, customer ratings, order trends, and restaurant sales distribution.

The dashboard presents key performance indicators and interactive visualizations to support data-driven business decisions.

## Project Objectives
- Analyze total sales, total orders, average ratings, and average order value.
- Track monthly, daily, and weekly sales trends.
- Compare sales performance across different food types.
- Analyze quarterly sales and customer ratings.
- Identify the top five cities based on sales.
- Explore sales performance using month and restaurant filters.
